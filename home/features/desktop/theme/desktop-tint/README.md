# macOS wallpaper-affinity surfaces

This is the **desktop tint / Chameleon** material, independent of Liquid Glass
and of the Matugen accent palette. The initial consumers are AI usage cards,
session-switcher cards, and Strata's Finder content background.

## Extracted implementation

Reference: the user's Mac, macOS 27.0.1, build 26A434. Inspected through LLDB on
the existing `macos` SSH connection. No wallpaper or appearance preference is
left changed by the investigation.

The actual implementation spans three frameworks:

1. AppKit's `NSVisualEffectView`, material **18 (`contentBackground`)**, requests
   CoreUI's material layers. In Finder the resulting layer tree contains an
   opaque `fill` and a **`CAChameleonLayer` named `desktop tint`**.
2. SkyLight's `CGXWindow::resolved_chameleon_color()` calls
   `DesktopEffectsGetAverageColor()`. This obtains each desktop surface's color
   in the intersecting **window rectangle**, then combines surfaces with weights
   proportional to their intersecting areas. It does not sample intervening apps.
3. QuartzCore's Chameleon renderer composites the context's color over the
   material fill. It is a uniform color for each window, not a blurred image.

Constants read from code/data and live Core Animation properties:

| Parameter | Extracted value |
|---|---:|
| Finder content fill, each sRGB component | `0.11759999394416809` |
| Chameleon layer opacity, float32 | `0.10000000149011612` |
| Desktop payload sampling scale | `0.125` |
| Payload sample texture | `MTLPixelFormatBGRA8Unorm` (70) |
| Capture color space | extended sRGB |
| Integral texture | RGBA32Float (125), MPS image integral |
| Integral row alignment | 64 bytes / four float4 pixels |
| Mean-color quantization | six bits |
| Default desktop payload update interval | 0.1 seconds |

`CGXWindow::evaluate_tag_bit_change()` constructs the payload with scale
`0x3e000000` (float32 0.125). `desktop_window_effects_update()` captures the
desktop, copies it using `ShaderComposer::SimpleTexture()` and its linear
sampler into the reduced BGRA8 texture, then uses `MPSImageIntegral`.

`Payload::average_color()` is **not quite a conventional rectangular mean**:

- Intersect with the desktop and transform into the payload's 1/8-scale space.
- Use truncated sample coordinates/extents for integral-image lookup.
- Keep fractional scaled width/height for the float32 area divisor.
- For nonzero x, the left integral-image index is **x**, not x-1.
- Compute `A + D - B - C`, divide by the fractional area, clamp each channel.
- Quantize RGBA as `min(floor(value * 64), 63) * float32(1 / 63)`.

The unusual index and partial alpha were verified by **calling Apple's actual
function with a synthetic 8×8 integral image**. `test_desktop_tint.py` contains
its captured results, rather than expected values generated by the port.

### Working gamut matters

Chameleon blends in **encoded destination working RGB**, after color conversion,
not in linear light. The reference Mac composites in Display P3. Mixing in sRGB
first visibly underestimates the secondary channels of saturated wallpapers.

The port therefore converts the quantized premultiplied sample into the reference
Display P3 gamut, composites there, and returns sRGB for GTK and Qt. The local
compositor can then color-manage those opaque pixels for its own display/HDR.
Both spaces use the standard sRGB transfer curve and D65 white point. Gamut
matrices derive from the standard primaries, not a fitted saturation coefficient.

Native AppKit versus reconstructed flat-layer captures matched within **one
8-bit channel step** for black, midgray, white, RGB primaries and a mixed color
when the same working gamut was used. Remaining raster rounding is not claimed
to be byte-identical across Apple's and Linux's rendering stacks.

## Ownership and reuse

- Hyprglass `desktop-affinity.patch`, `DesktopTint.inc`, and
  `DesktopTintMath.hpp`: same-frame compositor backend. A pass immediately after
  wallpaper rendering captures its actual fade at 1/8 logical resolution, before
  desktop icons, app windows, and popups. Native integral arithmetic, six-bit
  quantization, and encoded-P3 composition feed neutral surfaces later in that
  same render pass. There is no independent tint animation or polling delay.
- Strata protocol v4 supplies content/footer and inactive-sidebar planes;
  toolbar/base and sidebar glass body fills use the same window tone. Older
  compositors retain the GTK fallback. `strata/config/style.css` clears negotiated
  compositor-owned planes, including inactive descendants; a window-local GTK
  provider cannot style those descendants. Its higher-priority variable overrides
  also prevent the asynchronous fallback provider repainting opaque planes.
- QuickShell `NeutralSurfaces.qml` sends card geometry, hover state, and viewport
  clips through `hyprglass.layer`. The compositor owns card colors; Qt retains
  foreground ink, brand accents, borders, and selection overlays.
- `../desktop_tint.py`: shared sampling, integral-image arithmetic, quantization,
  gamut conversion, material composition, and service/CLI fallback.
- `desktop-tint.service`: owns decoded wallpaper payloads and the local socket.
  It queries hyprpaper's live per-monitor wallpaper, including picker previews,
  independently of cached accent palettes and older wallpaperctl binaries that
  leave `displayed` stale. Without live IPC it falls back to
  `~/.local/state/wallpaper/displayed`, then `current`.
- `~/.local/state/wallpaper/desktop-tint.json`: shared default roles and Strata
  window colors. Written atomically, only when data changes.
- `quickshell/config/theme/Theme.qml`: shared `windowSurface`, `cardSurface`,
  `cardSurfaceHover`, and `neutralBorder` roles.
- `quickshell/config/theme/WallpaperTint.qml`: reusable per-window sampler.
  Pass the screen and body rectangle, excluding compositor shadow padding. All
  cards inside one window use that window's uniform sample, like AppKit.
- `strata/wallpaper-tint.rs`: live scoped CSS variables. The existing skin and
  compositor gradients consume those variables; geometry and glass masks retain
  their existing owners.

Finder content uses its extracted fill. Card, hover, border, and footer roles
keep their existing neutral bases and apply the same extracted material logic.
Brand colors and text do not inherit the tint.

Wayland does not expose a client's global coordinates. Strata's bridge matches
compositor records by PID/title and, for duplicate titles, surface size. If two
windows remain indistinguishable, it uses the shared focused-screen sample;
it does not assign a different window's sample. This routing fallback is separate
from the extracted material arithmetic. Protocol-v4 Strata instead supplies
surface-local geometry directly to the compositor, avoiding PID/title matching.

Focused private-compositor proof (Nov 7): body/toolbar match through 25+
intermediate colors of a real wallpaper fade, within one 8-bit channel step of
the same-frame native material reference. Active/inactive sidebar, footer, and
QuickShell card red/blue pairs verified. A deliberately stale CPU fallback
palette cannot repaint compositor-owned Strata planes. This is an SDR
single-monitor proof, not universal pixel parity.

## Re-extraction and checks

```sh
python3 extract.py --host macos --output /tmp/opencode/desktop-tint-reference.json
# Within the repository's Python environment containing numpy and Pillow:
python3 -m unittest test_desktop_tint -v
desktop-tint sample GLOBAL_X GLOBAL_Y WIDTH HEIGHT
```

`extract.py` records framework UUIDs, native disassembly and the synthetic-payload
oracle. It attaches to Finder briefly and detaches; it changes no preferences.
The oracle's synthetic structure layout is specific to the recorded OS build.
